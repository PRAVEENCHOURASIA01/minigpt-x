# TinyStories Dataset Documentation

## Source & Provenance
- **Dataset**: `roneneldan/TinyStories` (specifically `TinyStoriesV2-GPT4`)
- **Hub Repository**: [https://huggingface.co/datasets/roneneldan/TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories)
- **Paper**: *"TinyStories: How Small Can Language Models Be and Still Speak Coherent English?"* by Ronen Eldan and Yuanzhi Li (Microsoft Research, 2023).
- **License**: CDLA-Permissive-2.0 / Open Data Commons.

## Description
TinyStories consists of synthetic short stories generated by GPT-3.5 and GPT-4 using vocabulary and concepts accessible to a 3- to 4-year-old child. Stories feature simple narrative structures, basic grammar, and moral or playful resolutions. Individual stories in the raw text files are demarcated by `<|endoftext|>`.

## Download Specification
Per project requirements:
1. **Train split** (`data/raw/train.txt`):
   - The first 300 MB of `TinyStoriesV2-GPT4-train.txt` was fetched via HTTP Range requests (`bytes=0-314572799`).
   - Sliced cleanly at the final story separator `<|endoftext|>`.
   - File size: **314,571,949 bytes** (300.00 MB).
   - Total characters: **314,443,348**.
   - Total stories: **384,130**.
   - Average story length: **818.6 characters**.

2. **Validation split** (`data/raw/valid.txt`):
   - Full `TinyStoriesV2-GPT4-valid.txt` downloaded.
   - File size: **22,502,601 bytes** (21.46 MB).
   - Total characters: **22,493,387**.
   - Total stories: **27,630**.
   - Average story length: **814.1 characters**.
